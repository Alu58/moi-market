# Moi Market

Moi Market is a static product-advertising site. Sellers submit product details to the admin through WhatsApp; the admin reviews and manually publishes approved listings.

## GitHub Pages

The GitHub Actions workflow deploys the site to GitHub Pages when changes are pushed to `main` or when the workflow is run manually. The site consists of `index.html`, `styles.css`, and `app.js`; there is no build step.

The product catalogue is currently empty. Seller submissions open WhatsApp and do not create listings automatically; the site does not process payments or provide checkout.
